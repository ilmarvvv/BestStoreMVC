<h1>🛍️ BestStoreMVC</h1>
  <p><strong>BestStoreMVC</strong> is a web application built with ASP.NET MVC that helps manage a small retail store. It allows administrators to manage products, customers, and orders while providing basic reporting tools.</p>

  <h2>⚙️ Technologies Used</h2>
  <ul>
    <li>C#</li>
    <li>ASP.NET MVC</li>
    <li>Entity Framework</li>
    <li>SQL Server</li>
    <li>HTML, CSS, Bootstrap</li>
  </ul>

  <h2>📦 Installation</h2>
  <ol>
    <li>Clone the repository:
      <pre><code>git clone https://github.com/ilmarvvv/BestStoreMVC.git
cd BestStoreMVC/BestStoreMVC</code></pre>
    </li>
    <li>Open the solution <code>BestStoreMVC.sln</code> in Visual Studio.</li>
    <li>Restore NuGet packages.</li>
    <li>Configure your SQL Server connection string in <code>Web.config</code>.</li>
    <li>
      <strong>Database Setup:</strong>
      <ul>
        <li><strong>If using Code First:</strong> Open the <em>Package Manager Console</em> and run:<br>
          <pre><code>Update-Database</code></pre>
          This will create the database and tables automatically.
        </li>
        <li><strong>If using Database First:</strong> Make sure your database exists and the connection string is correct.</li>
      </ul>
    </li>
    <li>Run the application (F5 or click "Start").</li>
  </ol>

  <h2>🚀 Features</h2>
  <ul>
    <li>CRUD operations for products</li>
    <li>Customer management</li>
    <li>Order processing</li>
    <li>Sales and inventory reporting</li>
  </ul>
